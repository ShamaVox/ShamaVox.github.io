Production proof

A multi-agent catalog platform built from proof of concept to production.

Before starting shamakeskar, I was cofounder and CTO of an AI-native wholesale platform for boutique retailers. I designed and built the system and shipped it to paying customers.

TimelineProof of concept to MVP in four months, then production.
SystemPython, FastAPI, Next.js, Postgres, pgvector, Redis, AWS, commercial LLM APIs, Datadog.
BusinessCatalog data delivered into retailer stores with sizing and color sync.

Supplier catalogs arrived in every format imaginable. Colors were abbreviated, size runs were written five different ways, and product images came in every size and resolution. Retail buyers were spending days retyping the data into their stores.

Getting a model to read a catalog was the easy part. The hard part was making every field correct on data nobody had seen before. So I built the checking before I built the features: a golden set of real examples, field-level accuracy tracking, and prompt and model versions logged with every output.

The work was split across specialized agents for extraction, sizing, quantities, and color, coordinated by plain deterministic code. I chose models by how they scored against the golden set—not by how impressive the demo looked—and made every failure traceable to one place.

IngestionAny supplier catalog, any layout.

Trust layerValidate, repair safely, and route uncertainty.
DeliveryPublish into the retailer's store.
Correction loop: every retailer fix returned to the review queue and eval set, so the system got better with use.
